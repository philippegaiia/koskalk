# Recipe Workbench

## Align workbench values on localized decimals
Workbench percentages render with exactly two decimals from first paint. Soap oil weights use adaptive precision by unit and magnitude, while additive and cosmetic row weights retain three decimals. Numeric table values use the shared responsive decimal anchor and locale separator; calculations keep their unrounded precision.
