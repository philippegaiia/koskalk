# Translations

## Per-locale interface overrides via InterfaceTranslations
Manage per-locale interface overrides through the Filament InterfaceTranslations resource (DB-backed via spatie/laravel-translation-loader; English source of truth is lang/en/<group>.php). Do not edit app lang/<locale>/ files for interface strings.
