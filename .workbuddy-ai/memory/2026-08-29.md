## Code review: bd103fb3 (branch codex/ingredient-guidance-refresh)

Reviewed commit `bd103fb3` "fix: revalidate stale locales in all guidance modes" in worktree
`.worktrees/ingredient-guidance-refresh`. Review only, no code changes.

Change: `IngredientGuidanceChangePlanner::plan()` dropped the
`$mode === GuidanceLocalization` gate, so a text-identical locale with a stale
`source_fingerprint` now gets a `revalidate` decision in both guidance modes.

Observed (throwaway test, since deleted): the `revalidate` path sets `refreshMetadata = true`, and
`IngredientTranslationService::sync()` rewrites `origin` and `prompt_version` alongside the
fingerprint, so a stored `reviewer_edited` row becomes `ai_generated` on revalidation.

**CORRECTION — the above is NOT a defect.** I had not read the approved design spec
(`docs/superpowers/specs/2026-08-28-ingredient-guidance-refresh-corrections-design.md`). It mandates
this: line 52 says an approved `revalidate` updates "source fingerprint, origin, and prompt version";
line 101 says "AI-generated **or revalidated** rows receive AI provenance and the localization prompt
version". The behaviour is by design. I wrongly inferred intent from a test instead of the spec, and
over-read invariant "Reviewer edits cannot silently inherit AI provenance" (line 146) as implying the
converse. It does not. Retaining historical human authorship would need a design change — a separate
audit field — not a planner patch.

Also noted: `$mode` is now unused in `plan()` (and `$editedFields` already was); both call sites
still pass them — confirmed real, low-risk cleanup, not a blocker. The review-item increase is
intentional (design line 147 gates revalidation-only changes behind human review).

**Surviving item (new):** design spec line 47 still scopes revalidation to "a localization-only run",
but bd103fb3 widened it to both guidance modes. Commit updated the plan doc, not the design doc —
minor spec drift worth aligning.

Verification: 17 tests pass in the two changed files; 39 pass across the wider enrichment/
guidance suite; Pint clean. No PHPStan/Larastan in this project.
