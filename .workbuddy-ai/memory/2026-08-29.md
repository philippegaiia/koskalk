## Laravel / Livewire conventions behind the nit 2 and nit 3 calls (2026-08-29)

Checked against official docs rather than priors.

**`Route::redirect` is URI → URI, by design.** Laravel 13 routing docs describe it as redirecting to
"another URI"; every example is a path. Mechanism: `Router::redirect()` stores the destination as a
route *default* (`destination`, `status` — both reserved parameter names), and `RedirectController`
builds a `Route` from it and calls `$url->toRoute()`. A route name would be read as a path. There is
no name-based variant to switch to.

**Closure routes and `route:cache` — the old rule is obsolete.** Pre-Laravel-11 guidance (still
repeated across community sites) says closure routes cannot be cached. In this codebase they can:
`Route::prepareForSerialization()` wraps the action in `SerializableClosure::unsigned()`, the 13.x
Route Caching docs no longer carry the old "exclusively controller-based routes" caveat, and
`route:cache` succeeded with a closure route in a live experiment. I could not pin the exact version
from the release notes, but the three signals agree.

**Livewire `#[Locked]` is the documented pattern I used.** The docs' canonical example is
`#[Locked] public $postId;` set from `mount($id)` — identical in shape to the committed
`#[Locked] public string $section` set from `mount(string $section)`. Listed use cases include
"preserve authorization-sensitive data throughout component lifecycle" and "protect any public
property that acts as a security boundary". Caveat from the docs: locked properties remain writable
from PHP, so don't feed untrusted input into them server-side.

**Why keep the explicit `mount()`.** Livewire lets you omit `mount()` when a prop name matches a
public property. Doing that here would need `public string $section = '';` — and a caller that forgot
`:section="$section"` would silently render a page with no section at all. The required `mount()`
parameter turns that into a loud `Unable to resolve dependency` failure, which is precisely what
caught `ProductionBenchNotificationTest`. Silence was the whole disease in nit 3.
