## Gotchas hit (now in reference/css-and-ui.md)

- Dev-server CSS is **unminified** — compact `grep -o` patterns silently match nothing, and
  BSD `grep` has no `\s`. I briefly concluded `max-w-app` "wasn't compiling" on that basis.
- Tailwind's dev cache **keeps** rules for deleted classes, so the bundle showing both
  `.max-w-[1180px]` and `.max-w-app` is expected, not a failed swap.
- `npm run build` is blocked in this sandbox (Vite `loadEnv` reads `.env`). Use `?direct`.
- `Illuminate\Testing\TestView` has **no `toHtml()`**. Use `view('welcome')->render()`.
